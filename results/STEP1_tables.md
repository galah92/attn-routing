# Step 1: does attention predict expert overlap beyond distance?

300 sequences x 1024 tokens (150 eval / 150 selection, stratified by domain, `results/split.json`). Pairs sampled per sequence and distance bin (all d = 1 pairs, else up to 2000), same pairs for every layer. Spearman per sequence, then mean over sequences with a 1000-resample bootstrap 95% CI over sequences. **Main variant: sink (j = 0) excluded, distinct tokens (ids[t] != ids[j]).** All numbers below are on the eval split unless stated. Full table: `step1_corr.csv`.

`partial` = partial Spearman controlling for the exact distance d within the bin (wide bins still contain distance variation, which drives both attention and overlap).
